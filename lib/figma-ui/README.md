# lib/figma-ui

The in-game half of the Figma pipeline: Luau modules that rebuild exported Figma frames as Roblox GUI and give every key the same feel. Reference implementation from a shipped prototype; copy it into a game and wire the four inputs below.

| Module | What it does |
|---|---|
| `Render.luau` | Builds a generated layout table node for node at the Figma coordinates: solid and linear fills (UIGradient), radial fills (soft-ellipse fallback), tiled textures, inner strokes, ink drops, soft and inner shadows, blur ellipses, sparkles, glyphs and chevrons. Names every instance after its layer, wires every keycap and every `tab/`, `btn/`, `seg/` layer through `Motion.key`, fits text to its box, builds lazily on first open. |
| `FKit.luau` | Luau port of `tools/figma/kit.js`, for windows built in code (settings, profile, popups) so they match the Figma ones exactly. |
| `Motion.luau` | Every UI tween: window open/close, row cascade, tab glide, idle gloss, can't-afford shake, maxed pop, the one key press-in, `settle` on success. |
| `Kit.luau` | Square UI template: keycap buttons (ink body, lip, face, gloss), steel plates, text with ink outline, sounds per key kind. |
| `Describe.luau` | Description card shown on hover / long-press for any `btn/`, `tab/`, `seg/` layer. |

## What your game provides

| Required | Shape |
|---|---|
| `ReplicatedStorage.Shared.Icons` | `{ [iconName] = "rbxassetid://…" }`; every `ico/<name>` layer must resolve |
| `UI/Sfx` | one function per UI event (`press_down`, `press_up`, `hover_tick`, `tab_switch`, `window_open`, `buy_ok`, `cant_afford`, …) |
| `UI/Descriptions` | `{ [layerName] = { title, body } }` for every key name you use |
| `UI/Figma/Layouts/*` | generated by `tools/figma/build_layouts.py` |
| `UI/Figma/IconAlias` | optional `{ [oldName] = newName }` safety net |

`FKit` clones one generated window's header as the source for code-built windows (`Layouts.Mine_Shop` in the original); point it at any window of yours.

## Status

Compiles and lints clean. It ran in a Roblox prototype (1,036 keys wired, every window opened and pressed by the headless UI harness), but it hasn't been wired into a game from this repo. See the [Figma UI playbook](../../docs/playbooks/figma-to-roblox-ui.md).
