aaa-kit · lib/surfacebake

Algorithm textures, baked onto the model

Every texel of the UV map is traced back to the 3D point on the model it paints. The algorithms run there (noise, Voronoi, edge distance, ambient occlusion, a reaction-diffusion render projected triplanar), so the result is seamless across UV islands and wear lands on real edges. The same recipe tables drive the Luau library that writes these maps into a Roblox SurfaceAppearance.

The maps (UV space)

1 · Rasterise in UV spaceEach triangle is drawn into the texture by its UVs. Every covered texel stores the object-space position, normal and tangent frame (a G-buffer), then islands are dilated 4 texels so mipmaps never bleed.
2 · Measure the surfacePer-vertex AO (hemisphere rays) finds crevices. Distance to the nearest sharp edge, in studs, finds rims to chip. Both are geometry, not UV, so they are the same width on any tessellation.
3 · Run the recipeMasked layers (rust, chips, grime, moss, cracks) mix colour, roughness and metalness. Height is sampled at ±1 texel along the tangents in 3D, giving an OpenGL normal map without seams.
